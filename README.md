# Mirrors: an interactive optics lesson

Play it in the browser: https://pritam-dev-metabook.github.io/mirrors-web/

Desktop Chrome or Edge recommended (about 28 MB on first load). Add `?stage=S05` (S02 to S08) to start at a scene.

This repository holds only the playable Web build, published from the private project on 2026-10-16 19:45
(project commit 5d12487). Credits and licences for the music, sounds, voice and models are in the lesson under
Menu > Credits.
